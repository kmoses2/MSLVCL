# 말씀 암송 NIV

NIV 성경 구절을 소리 내어 외우면, 본문과 한 단어씩 맞춰 보고 틀린 곳을 표시해 주는 웹앱입니다.
휴대폰 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 열립니다.

## 쓰는 법

1. 구절을 고르고 마이크 버튼을 누른 뒤 영어로 암송합니다. 다 했으면 빨간 버튼을 누릅니다.
2. 결과 화면에서 틀린 곳을 확인합니다.
   - 틀린 단어: 빨간 글씨, 위에 작게 들린 말
   - 빠뜨린 단어: 빨간 점선 상자
   - 본문에 없는 말: 주황색 취소선
3. 마이크가 잘못 알아들은 단어는 눌러서 맞음으로 바꿀 수 있습니다.
4. 최근 3번을 연속으로 100% 맞히면 ‘암송 완료’가 됩니다.

목록의 구절 카드에는 NIV 본문 전체와 한글 본문이 함께 보입니다. 연습 화면에서는 한글 본문이 위에 보이고,
영어 본문은 가리기(단어 길이만큼 빈칸) / 첫 글자 / 전체 보기로 바꿔 볼 수 있으며, ‘듣기’로 읽어 줍니다.
마이크를 쓸 수 없을 때는 키보드로 입력해서 채점할 수도 있습니다.

## 채점 규칙

| 구분 | 내용 |
| --- | --- |
| 틀림으로 보는 것 | 단어가 하나라도 다르면 틀림. `plans` ↔ `plan`, `submit to` ↔ `acknowledge`(NIV 1984 표현) |
| 보지 않는 것 | 대소문자, 문장부호, 숫자 표기(`1` ↔ `one`), 붙여 쓰기(`every one` ↔ `everyone`), 영국식 철자(`honour` ↔ `honor`) |
| 음성일 때만 맞게 보는 것 | 소리가 같은 단어(`Son` ↔ `sun`, `peace` ↔ `piece`). 마이크로는 구별할 수 없기 때문입니다. |
| 장절 | “John three sixteen”처럼 앞뒤에 말해도 채점하지 않습니다. |

점수는 `맞은 단어 ÷ (본문 단어 + 본문에 없는 말)`이며, 모든 단어가 맞아야만 100%가 됩니다.

## 구절 추가

1. ‘새 구절 추가’에서 성경 66권 중 책, 장, 절을 고릅니다. 여러 절(예: 3:16-17)이나 장 전체도 고를 수 있습니다.
2. ‘NIV 본문 열기’를 누르면 성경 앱(YouVersion)이나 bible.com에서 그 구절이 NIV로 열립니다.
   길게 눌러 복사한 뒤 돌아와서 ‘붙여넣기’를 누릅니다.
3. 저장합니다.

절 번호, 각주 표시(`[a]`, `(A)`), 링크, “John 3:16 NIV” 같은 줄은 자동으로 지워지고, 장절이 비어 있으면 채워집니다.
고른 장절과 붙여넣은 본문의 장절이 다르면 알려 줍니다. 없는 장절(예: 요한복음 3:40)은 저장되지 않습니다.
본문을 가지러 성경 앱에 다녀오는 동안 적던 내용은 저장되어 있다가 다시 채워집니다.
한 단어씩 채점하므로 저장하기 전에 본문이 정확한지 확인해 주세요.

NIV 전체 본문은 Biblica의 저작물이라 앱에 넣어 둘 수 없습니다. 그래서 구절을 고르면 본문은 성경 앱에서 가져오는 방식입니다.

### 본문 자동으로 가져오기 (선택)

YouVersion의 개발자 서비스(YouVersion Platform, 비영리 용도 무료) 앱 키를 설정 화면에 넣으면, 구절을 고르기만 해도 NIV 본문이 자동으로 채워집니다.

1. https://platform.youversion.com 에 YouVersion(성경 앱) 계정으로 로그인합니다.
2. 앱을 하나 만들고 앱 키(App Key)를 복사합니다. 번역본 사용 신청이 있으면 NIV를 신청합니다.
3. 암송 앱 › 설정 › ‘본문 자동으로 가져오기’에 붙여넣고 ‘연결 확인’을 누릅니다.

키는 그 기기에만 저장됩니다. 직접 고치거나 붙여넣은 본문은 덮어쓰지 않고, ‘자동으로 가져오기’를 누를 때만 바꿉니다.

### 한글 본문

앱 키가 있으면 한글 본문도 YouVersion에서 가져옵니다. 설정의 ‘한글 본문’에서 번역본을 고르거나(기본: 개역한글, 개역개정이 있으면 개역개정) 보여 주지 않게 할 수 있습니다.
이미 있는 구절에도 앱을 열 때 자동으로 채워집니다. 한글 성경을 쓰려면 YouVersion Platform의 Licensing에서 해당 출판사(예: Korean Bible Society) 사용에도 동의해야 합니다.
키가 없으면 구절 편집 화면에서 한글 본문을 직접 적을 수 있습니다. 한글 본문은 보여 주기만 하고 채점에는 쓰지 않습니다.
요청 형식은 YouVersion 공식 SDK(`@youversion/platform-core`)를 따랐습니다.
장·절 수는 NIV 기준입니다(표준 영어 성경 구분, 요한삼서는 15절).

## 브라우저

- iPhone: Safari. 설정 › 일반 › 키보드에서 받아쓰기가 켜져 있어야 할 수 있습니다.
- Android, PC: Chrome 또는 Edge
- 카카오톡 같은 앱 안의 브라우저에서는 음성 인식이 안 될 수 있습니다. 메뉴에서 다른 브라우저로 여세요.
- 음성은 브라우저의 음성 인식 서비스(Chrome은 Google, Safari는 Apple)로 보내져 글자로 바뀝니다. 인터넷 연결이 필요하고, https 주소에서만 동작합니다.

## 저장

구절과 기록은 그 기기의 브라우저(localStorage)에만 저장되고 서버로 가지 않습니다.
설정 화면에서 백업 파일로 내보내고 불러올 수 있습니다.
iPhone Safari는 오래 쓰지 않은 사이트의 데이터를 지울 수 있으니 홈 화면에 추가해서 쓰는 것을 권합니다.

## 개발

빌드 과정 없이 정적 파일만 있습니다.

```sh
cd recite
npm start   # http://localhost:8080 (localhost에서도 음성 인식이 됩니다)
npm test    # 단위 테스트, Node 18 이상
```

| 파일 | 하는 일 |
| --- | --- |
| `lib/compare.js` | 본문과 암송을 단어 단위로 정렬하고 채점 |
| `lib/text.js` | 단어 나누기, 숫자·철자·동음이의어 처리 |
| `lib/books.js` | 성경 66권 이름(영어·한글·약어), 장절 해석·검사, 성경 앱 링크 |
| `lib/versification.js` | 66권의 장별 절 수 (NIV 기준) |
| `lib/youversion.js` | YouVersion에서 NIV·한글 본문 가져오기, 한국어 번역본 목록 (앱 키 필요) |
| `lib/cleanup.js` | 붙여넣은 본문 정리 |
| `lib/speech.js` | 브라우저 음성 인식 (자동 재시작, 중복 결과 정리) |
| `lib/store.js` | 구절·기록 저장, 백업 |
| `lib/starter.js` | 기본 구절 12개 |
| `app.js`, `styles.css`, `index.html` | 화면 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 오프라인 사용, 홈 화면 앱 |
